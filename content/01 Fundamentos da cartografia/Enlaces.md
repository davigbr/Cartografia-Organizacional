Enlaces são relações ou conexões entre diferentes [[Atuantes]]. Para evitar complexidade desnecessária, propomos dois níveis de mapeamento dos enlaces:

- **Nível 1**: É a classificação padrão utilizada na maioria dos mapas. Serve para identificar rapidamente o estado geral (onde o sistema sofre ou prospera). Usa-se apenas os 4 tipos básicos: composição, decomposição, captura e linha de fuga.
- **Nível 2**: É uma classificação detalhada, empregada apenas quando queremos mais nitidez sobre as relações. Cada tipo básico se subdivide em 3, totalizando 12 tipos.

## Nível 1

| **Tipo**            | **Descrição**                                                                                                                                                                                              |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Composição <br>🟢   | O encontro aumenta a potência de agir de pelo menos um dos [[Atuantes]], não produzido decomposição no outro. Há compatibilidade, fluidez e soma de forças. A energia circula livremente ou se multiplica. |
| Decomposição 🔴     | O encontro diminui a potência de agir de pelo menos um dos [[Atuantes]]. Há choque, bloqueio ou perda de energia por atrito. O agenciamento gasta mais energia para funcionar do que poderia.              |
| Captura <br>🟣      | Relação de poder unidirecional ou parasitária. A energia é drenada de um ponto para sustentar outro, ou é forçada a seguir uma órbita específica contra sua tendência natural.                             |
| Linha de Fuga<br>🟡 | Uma conexão não oficial, clandestina, inovadora ou que aponta para fora. A energia encontra um caminho alternativo para contornar bloqueios do território atual.                                           |

## Nível 2

| **Subtipo<br>Tipo**               | **Descrição**                                                                                                                                       | **Exemplo**                                                                                                                                                  |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Condução** Composição 🟢        | Ocorre quando a informação, decisão ou energia passa de A para B sem perda e sem alteração. É o "fio condutor" ideal. O output é fiel ao input.     | Dados fluindo limpos entre sistemas; uma ordem compreendida perfeitamente.                                                                                   |
| **Amplificação**<br>Composição 🟢 | O elemento A, ao passar por B, ganha magnitude ou alcance que não teria sozinho. O fluxo sai maior do que entrou.                                   | Uma ferramenta que triplica a produtividade; um ritual que eleva o moral do grupo.                                                                           |
| **Ressonância**<br>Composição 🟢  | Uma via de mão dupla onde A alimenta B e B alimenta A, criando um sistema que se auto-sustenta e cresce.                                            | Colaboração genuína entre áreas; alinhamento entre objetivo e tarefa.                                                                                        |
| **Interrupção**<br>Decomp. 🔴     | A energia encontra uma barreira intransponível e o fluxo cessa imediatamente. É binário: não passa.                                                 | Um veto burocrático; um sistema fora do ar; uma porta trancada.<br>                                                                                          |
| **Resistência**<br>Decomp. 🔴     | O fluxo passa, mas perde velocidade e força. Exige um esforço desproporcional para realizar uma tarefa simples. Gera "calor" (estresse).            | Lentidão no sistema; processos com etapas excessivas; má vontade interpessoal.                                                                               |
| **Dissonância**<br>Decomp. 🔴     | A energia chega do outro lado, mas chega alterada, confusa ou poluída. Gera imprevisibilidade e erro.                                               | Comunicação ambígua; dados não confiáveis; regras contraditórias.                                                                                            |
| **Indução**<br>Captura 🟣         | Uma força externa que altera a trajetória tendencial do atuante, puxando sua atenção e prioridade para um ponto específico.                         | Incentivos financeiros moldando comportamento; urgências constantes desviando o foco.                                                                        |
| **Extração**<br>Captura 🟣        | Uma relação onde A consome a energia de B para se manter funcional, sem devolver valor proporcional.                                                | Reuniões improdutivas; burocracia defensiva; apropriação de crédito alheio.                                                                                  |
| **Monitoramento**<br>Captura 🟣   | Uma conexão de leitura contínua que, por sua existência, altera o comportamento do observado (geralmente gerando defesa ou performance artificial). | Auditoria excessiva; microgerenciamento; vigilância eletrônica                                                                                               |
| **Desvio**<br>Fuga 🟡             | O fluxo contorna deliberadamente um ponto de Interrupção ou Resistência oficial para atingir o objetivo.                                            | Pular etapas de aprovação; comunicação informal para resolver problemas rápidos.                                                                             |
| **Transmutação**<br>Fuga 🟡       | O uso de um elemento para uma finalidade diferente daquela para a qual foi desenhado, adaptando-o à necessidade real.<br>                           | Usar uma planilha como banco de dados; usar uma sala de reunião como depósito.                                                                               |
| **Ruptura**<br>Fuga 🟡            | A linha abandona o agenciamento e cria um novo território do exterior. Invenção de uma nova lógica que não responde mais às regras antigas.         | Um projeto interno que vira uma startup independente (spin-off); o abandono total de uma ferramenta oficial para construir uma solução proprietária do zero. |
